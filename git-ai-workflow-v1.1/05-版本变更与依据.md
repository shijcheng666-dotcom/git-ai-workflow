# v1.1 版本变更与依据

## 版本策略与能力基线

v1.0 原目录和压缩包保留。v1.1 复制后增量更新，不初始化真实项目仓库、不迁移材料、不安装 Skill、不修改用户软件设置。

基线：独立项目仓库；单真实目录串行接力；明确启动读取；稳定规则、当前状态与主题知识分离；必要本地检查点自动、验收用户确认；未提交与暂存区保护；敏感材料识别；恢复前保护和新位置比较；HTML／软件分开验证；原始材料来源与决策替代关系；逻辑归档与不默认上传。上述能力全部保留。

## 演进清单

| 改动 | 理由与影响 | 验证方式 |
|---|---|---|
| 新增 AGENTS.md 短入口 | 对齐跨工具开放约定；不退役 PROJECT_RULES.md | 检查真实指针、关键安全边界；用户工具中首次只读核验 |
| 三种状态单独记录 | 防止保存、AI 检查和用户验收混淆 | STATE 三维表与模板／提示词一致性检查 |
| 工具接入登记与场景 12 | 核对路径与实际读取，自动加载不作假设 | 新会话只读测试；显式读取和自动加载区分 |
| 旧项目升级场景 13 | 不静默覆盖已确认有效规则 | 原版保留；新旧比对；先列改动再合并 |
| 数据处理边界提醒 | Git 不推送不能保证模型请求／索引不联网 | 规则检查；实际工具政策与公司允许范围需另核验 |
| 快速入门、详细文件说明 | 明确包／项目／集合区别和用户操作 | 文件数量、模板引用、场景与路径检查 |
| 保留工具专属检查点作为补充 | 工具撤销的覆盖范围和存储方式不同 | 对照官方文档；跨软件恢复仍走项目 Git |

没有退役既有规则。Git 分支、worktree、脚本和 Skill 仍为按需扩展，不默认加入。原 11 个场景保留，新增至 13 个。

## 公开依据及使用边界

网页查阅时间：2026-10-26。以下是方法和文档依据，不等于用户安装版本实测，也不是所有工具统一的强制标准。

- AGENTS.md 开放格式：https://agents.md/ 。支持用 Markdown 在项目中保存 Agent 指引；普通指针不能保证正文自动注入。
- TRAE 官方规则：https://docs.trae.cn/ide_rules 。列出 AGENTS.md 导入开关与项目规则；需核对地区版、安装版本与设置。
- Antigravity 官方规则：https://antigravity.google/docs/rules 。当前文档列出 AGENTS.md；原生规则触发和引用语法与 TRAE 不同，不跨工具照抄。
- 开源共享指引案例：https://github.com/Luligu/matterbridge-shelly/blob/HEAD/.agents/README.md 。规则只维护一份、工具入口做指引并检查读取；是作者实践，不作为所有加载语法的支持证明。
- Aider Git 集成：https://aider.chat/docs/git.html 。自动记录 AI 修改并保护原改动的工具实践；不照搬其自动处理未知改动或其他工具默认设置。
- Cline Memory Bank：https://docs.cline.bot/prompting/cline-memory-bank 。通过项目文件保存上下文的方法；本方案按用户需求缩减重复记录，不全量套六文件模板。
- Cline 检查点：https://docs.cline.bot/features/checkpoints 。独立影子 Git 仓库，不等于项目公共历史。
- Claude Code 检查点：https://code.claude.com/docs/en/checkpointing 。明确有跟踪范围限制，不能替代版本控制；不作为 Aime／TRAE 功能证明。
- Git worktree：https://git-scm.com/docs/git-worktree 。适合隔离独立工作，不是串行切换的必需步骤。
- 社区问题：https://github.com/openai/codex/issues/12128 。2026-02-18 报告规则发现边界问题，2026-02-24 经 PR #12639 关闭；仅支持核验实际读取，不宣称当前三个工具存在该旧缺陷。

Aime 自动加载 AGENTS.md、本地三个客户端的接力行为、数据请求与索引政策未在本次更新中实测。若自动加载失败仍可显式读取；若文件或 Git 权限不足只能讨论并交由具备授权的 Agent 操作。
