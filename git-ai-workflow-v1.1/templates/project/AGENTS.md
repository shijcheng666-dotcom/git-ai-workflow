# 项目协作入口

此文件是跨 Agent 的短入口模板。首次接入时根据项目实际文件路径核对指针；不在此复制完整规则、原始研究材料或敏感信息。工具能否自动加载本文件须逐工具核验；即使自动加载，也要按任务读取当前状态。

- 开工前实际读取根目录 `PROJECT_RULES.md`（完整规则）和 `STATE.md`（当前状态／交接），并按任务读取相关知识与来源材料；已有项目复用其他文件时，先将此处指针改为真实路径。
- 确认真实项目目录与 Git 仓库根目录一致，检查当前分支、已暂存／未暂存／未跟踪文件和最近提交。来源不明或冲突的改动，不覆盖、不丢弃、不顺带提交。
- Aime、TRAE、Antigravity 轮流编辑同一真实目录；上一工具任务、后台编辑结束且文件已保存后再接力。不得假定聊天或工具内检查点跨软件共享。
- AI 可按完整规则保存必要的**本地恢复检查点**；仅在用户明确确认对应范围后标记**验收版本**。提交前核对文件清单、暂存区、敏感信息和提交身份；不擅自推送、发布、重写历史或强制恢复。
- 修改后分别说明：①哪些文件已留档及检查点；②AI 实际检查、结果和未验证项；③用户已验收的范围或待验收。版本记录不是质量证明。
- 未核实模型请求、索引、留存及公司要求前，不读取敏感原文；不得因为不推送 Git 就认为资料不会联网。恢复旧版前先保护当前内容和资源，先在新位置比较，覆盖入口需用户确认。
- 有规则冲突、入口缺失或无法读取时说明并暂停冲突部分。项目详细信息只在 `PROJECT_RULES.md` 与 `STATE.md` 维护；本文件保持短小，不作重复事实源。
